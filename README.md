## Методика

| Параметр | Значение |
|---|---|
| Инструмент | Google PageSpeed Insights ([pagespeed.web.dev](https://pagespeed.web.dev/)) |
| Объект | страница с тарифами или SEO-услугами каждого агентства |
| Режимы | `mobile` и `desktop` |
| Дата замера | 25 октября 2026 |
| Регион и сеть | один IP и один тип подключения для всех замеров |
| Количество запусков | Несколько запусков с выбором лучшего результата для всех 12 сайтов |

**Формула общего балла:**

```
Балл режима = Производительность + Спец. возможности + Рекомендации + SEO + Агентный просмотр
Итого       = балл mobile + балл desktop
```

Четыре категории PageSpeed оцениваются по шкале 0–100. **Агентный просмотр** в отчёте показан как «пройдено из N проверок»: число N зависит от страницы (в этой выборке от 2 до 4). В сумму входит число пройденных проверок (колонка `agentic_passed`), а N записано в колонке `agentic_total`. Поэтому максимум для разных страниц немного различается: 400 плюс N для каждого режима.

Чтобы получить итог по классической шкале 4×100, вычтите `agentic_passed` из общего балла каждого режима. Значения агентного просмотра не нормируются и вносят в итог не более 3–4 баллов на режим.

## Описание файлов с данными

### `manifest.csv`

| Колонка | Описание |
|---|---|
| `file` | имя файла скриншота |
| `agency` | домен агентства |
| `tested_page_url` | адрес измеренной страницы агентства |
| `form_factor` | `mobile` или `desktop` |
| `report_url` | ссылка на сохранённый отчёт PageSpeed |
| `measured_date` | дата замера (`2026-10-25`) |
| `screenshot_date` | дата создания скриншота (`2026-10-28`) |
| `performance` | балл «Производительность», 0–100 |
| `accessibility` | балл «Специальные возможности», 0–100 |
| `best_practices` | балл «Рекомендации», 0–100 |
| `seo` | балл «Поисковая оптимизация», 0–100 |
| `agentic_passed` | агентный просмотр: сколько проверок пройдено |
| `agentic_total` | агентный просмотр: сколько проверок применимо к странице (2–4) |
| `total_score` | сумма четырёх категорий и `agentic_passed` для данного режима |

Файл в кодировке UTF-8 с BOM, поэтому корректно открывается в Excel.

### `data/reyting-seo-kompaniy-tashkent-2026-pagespeed.csv`

Сводная таблица результатов, та же, что опубликована в статье. Одна строка на агентство (12 строк), 18 колонок: адрес страницы, затем блок для мобильной версии и блок для компьютерной версии (ссылка на отчёт, четыре категории, агентный просмотр «пройдено» и «всего проверок», общий балл), и итоговая колонка «Всего». Кодировка UTF-8, разделитель запятая.

## Как проверить целостность файлов

Сравните хэши скриншотов с `sha256.csv`.

Windows (PowerShell, из папки `screenshots`):

```powershell
Get-FileHash *.png -Algorithm SHA256
```

macOS и Linux:

```bash
shasum -a 256 *.png
```

Совпадение хэша означает, что файл не изменялся после загрузки в репозиторий.

## Как повторить замер

1. Откройте ссылку из колонки `report_url` в `manifest.csv` или введите URL страницы на [pagespeed.web.dev](https://pagespeed.web.dev/).
2. Выберите вкладку «Мобильные» или «Компьютер».
3. Сравните четыре категории баллов.

Результаты PageSpeed меняются от запуска к запуску, а сайты агентств могли измениться после 25 октября 2026, поэтому новый замер даст другие цифры. Для сопоставимости сравнивайте со скриншотами из этого репозитория, а не с повторным запуском.

## Ограничения

- Это снимок на одну дату. Сайты агентств с тех пор могли измениться.
- Измерялась одна страница каждого сайта, а не сайт целиком.
- Баллы PageSpeed характеризуют техническое состояние страницы, но не качество SEO-услуг агентства.
- Лабораторный балл Lighthouse не равен полевым данным Core Web Vitals (CrUX), которые учитывает Google.
- Число проверок агентного просмотра зависит от страницы (2–4), поэтому эта метрика не нормирована: страница с большим числом применимых проверок может получить больше баллов. Для оценки влияния сравните два столбца «Итого» в таблице выше.
- Выборка неполная: в Ташкенте работает больше 12 SEO-агентств. Вошли те, у кого на момент замера была публичная страница с ценами или услугами SEO.
- Для каждого сайта и режима в таблицу вошёл лучший результат из нескольких запусков (правило одинаково для всех 12 сайтов), поэтому цифры стоит читать как верхнюю границу, а не как среднее. В архиве сохранены только скриншоты выбранных запусков.
- **Конфликт интересов:** SEO UZ является автором исследования и участником таблицы. Все скриншоты и ссылки на отчёты опубликованы, чтобы данные можно было проверить независимо.
- Ссылки на отчёты pagespeed.web.dev могут со временем перестать открываться. Подтверждением данных остаются скриншоты из этого репозитория.
